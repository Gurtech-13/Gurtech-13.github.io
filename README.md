# Gurtech-13.github.io

Static project listing for the [Python-Coderss](https://github.com/Python-Coderss) GitHub account.

- `index.html` — list of public repositories (most recently updated first)
- `repos/<name>.html` — one page per repository (rendered README, file listing, or empty-repo note)
- `style.css` — shared stylesheet (no frameworks, no build step, no JavaScript)

Pages are written and maintained by hand; GitHub data is checked with the `gh` CLI when the content needs refreshing.
