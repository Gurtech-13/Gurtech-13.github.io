This is a Next.js project bootstrapped with create-next-app. ## Getting Started First, run the development server: ``bash npm run dev # or yarn dev # or pnpm dev # or bun dev ` Open http://localhost:3000 with your browser to see the result. You can start editing the page by modifying app/page.js. The page auto-updates as you edit the file. This project uses next/font` to automatically optimize and load Geist, a new font family for Vercel. ## Learn More To learn more about Next.js, take a look at the following resources: - Next.js Documentation - learn about Next.js features and API. - Learn Next.js - an interactive Next.js tutorial.
