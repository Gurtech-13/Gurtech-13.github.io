The repository is a single self-contained presentation page: it explains cirrus cloud altitude (4,000–20,000 m), appearance, and formation (deposition onto dust particles), and covers the cirrus species — Castellanus, Fibratus, Floccus, Spissatus, and Uncinus — each with reference photos. The cloud image in the header swaps between two photos when clicked.
