Generated by `../make_readable.py`. **Do not edit this tree by hand** - edit the map in that script and regenerate.

`src/` is the decompiled original exactly as emitted and stays that way. This mirror only renames identifiers whose meaning is established (by an original error message, by a call site, or by a note in `DEOBFUSCATION.md`). Everything else keeps its emitted token, so a name here is either *known* or *untouched* - never a guess dressed up as a fact. Names marked **inferred** are the best reading of the class's use sites rather than something the source states.
