# readable_src

A readable mirror of `../src/` (the decompiled original). Generated by `../make_readable.py`; regenerate with `python3 make_readable.py`. See [`RENAME_MAP.md`](RENAME_MAP.md) for what was renamed and the evidence for each name.

Only identifiers this project has *established* are renamed. Classes and packages are rewritten globally so imports and `new` / `extends` stay consistent; members only inside the classes listed in the map's Scope section. Untouched names keep the decompiler's delimited form.
